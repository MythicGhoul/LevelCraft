# Documentation changelog

## Initial documentation release — November 2026

- Introduced a complete GitHub-native Markdown documentation collection.
- Added separate guides for all eleven skills.
- Documented character creation, Total Level, prestige, guild promotions and quests.
- Added rarity, Power Level, forging, sockets and magic reference sections.
- Added corruption, shrines, bosses, world encounters and map-integrations guides.
- Added NPC shops, economy, trading, clan and party pages.
- Added command, permission, PlaceholderAPI and YAML reference pages.
- Added admin security, performance, troubleshooting, backups and developer notes.

### Scope note

This is a documentation release, not a plugin changelog. It does not assert that these features were all introduced at once or that all historical design concepts are available in every LevelCraft version.

## For future releases

Add an entry with the actual plugin version and publication date. Record changed menus, command syntax, configuration keys and behaviour that affects existing guides.
