# Contributing to the LevelCraft documentation

Documentation lives in [docs/](docs/README.md). Each feature has its own Markdown page.

1. Find the existing page, or create a new `.md` file in the appropriate feature folder.
2. Add a relative Markdown link to the new page in [`docs/README.md`](docs/README.md).
3. Use clear headings, verified commands, and minimal YAML examples. Document build-specific differences honestly.
4. Verify internal links before committing (every link should open a real Markdown file in this repository).
5. Do not upload personal server data, private source code, tokens, webhooks, private items or other credentials.

GitHub renders the files automatically. No special build step, site workflow or GitHub Pages configuration is required.
