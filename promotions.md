# Promotion exams

Promotion exams are a specialised quest category that advances players through the guild-rank ladder: **F → E → D → C → B → A → S**.

## Structure

An exam can combine several normal objective types with a special encounter, usually culminating in a rank-appropriate boss. Rewards may execute console commands to assign progression or grant equipment.

## Recommended server design

| Rank earned | Design emphasis |
| --- | --- |
| E | Introduce combat and basic preparation |
| D | Reinforce mechanics and mixed objectives |
| C | Add coordination or stronger boss moves |
| B | Require more specialised gear |
| A | Demand advanced progression and preparation |
| S | Endgame trial and significant accomplishment |

This is an **administrative design guide**, not a claim that every server ships with these exact encounters. Rank-exam definitions and boss data live in configured quest and boss resources.

## Setting up an exam

1. Create the quest or questline with the correct rank restriction.
2. Define prerequisite objectives and the final encounter.
3. Assign reward actions, including any server-specific rank grant.
4. Test completion, claiming, repeatability and death/party scenarios.
5. Test with an F-rank account rather than admin bypass permissions.
