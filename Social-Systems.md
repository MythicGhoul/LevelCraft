# Playing together

LevelCraft supports several multiplayer interaction systems without replacing normal Minecraft cooperation.

| System | Primary purpose |
| --- | --- |
| [Parties](https://github.com/MythicGhoul/LevelCraft/wiki/Social-Parties) | Small-group cooperation and nearby XP sharing |
| [Clans](https://github.com/MythicGhoul/LevelCraft/wiki/Social-Clans) | Longer-term organisations, ranks and territory |
| [Direct trading](https://github.com/MythicGhoul/LevelCraft/wiki/Social-Player-Trading) | Item-for-item exchange between two players |
| [Nametags](https://github.com/MythicGhoul/LevelCraft/wiki/Social-Nametags) | Character identity, guild rank and health display |

A party and a clan are not the same entity. A player can belong to a persistent clan but temporarily group with a different team for a boss fight, if server rules allow it.
