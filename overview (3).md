# Getting started

LevelCraft changes progression, not the basic goal of survival. Players gather resources and battle mobs as usual, but skills, guild titles, quest lines, mana, rare equipment and world threats give those activities additional purpose.

## Who this documentation is for

- **Players:** See [Your first character](first-character.md), [Skills](../progression/skills/index.md), [Quests](../quests/overview.md) and [Equipment](../equipment/overview.md).
- **Staff:** See [Installation](installation.md), [Admin setup](../administration/overview.md), [Configuration](../reference/configuration.md) and [Troubleshooting](../administration/troubleshooting.md).
- **Developers:** See [Architecture](../development/architecture.md) and [Integrations](../reference/integrations.md).

## Essential concepts

| Concept | What it means |
| --- | --- |
| Skill level | Progress in a specific activity such as Mining or Sorcery. |
| Total Level | An overall character-progression measurement, separate from vanilla XP. |
| Guild rank | F, E, D, C, B, A or S; promotion is handled through exam progression. |
| Race and path | Character identity, buffs and trade-offs chosen during onboarding. |
| Rarity | Equipment quality tier, affecting how valuable a given item is. |
| Power Level | Equipment requirement used to calculate effectiveness. |
| Coins | Economy rewards and transactions, separate from skill XP. |
| Souls | A protection/progression resource connected to death mechanics. |
