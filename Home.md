# ⚔️ LevelCraft Wiki

> **Forge Your Path · Master Your Craft · Become Legend**

Welcome to the official **LevelCraft** knowledge base — a Minecraft RPG progression plugin by **MythicGhoul**.

Explore the systems that transform ordinary survival into an RPG: independent skills, selectable races and paths, guild promotions, rare equipment, spellcasting, quests, player-run clans, and a world threatened by corruption.

## ℹ️ About this documentation

These guides describe systems from previously reviewed LevelCraft project materials. **Exact commands, defaults and behaviour can differ between builds**; verify build-specific examples against the version installed on your server.

The documentation contains no private source files or server credentials.
