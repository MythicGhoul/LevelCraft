# Races

Races define the character's origin and modify strengths and weaknesses. The current six-race character selection set is:

| Race | Character fantasy | Roleplay orientation |
| --- | --- | --- |
| **Human** | Adaptable adventurer | Generalist, flexible progression |
| **Elf** | Agile woodland lineage | Precision, mobility and nature |
| **Dwarf** | Resilient craftspeople | Mining, industry and endurance |
| **Beastkin** | Instinct-led survivor | Tracking, hunting and reflexes |
| **Infernal** | Fire-bound lineage | Risk and aggressive power |
| **Celestial** | Radiant-born lineage | Protection and mystical support |

!!! warning "Exact stats are version-dependent"
    The table describes each race's theme, **not a verified list of numerical passive buffs**. Read the signs, GUI or chat selection details on your actual server for the precise bonuses and drawbacks. This avoids presenting older balancing values as current.

## Choosing a race

1. Enter the designated race hall or open the configured character-creation interface.
2. Inspect the race's bonuses and negative traits.
3. Select it and accept the confirmation.
4. Reopen the character sheet to verify the correct race is recorded.

## Server administration

Admins can reset race selection when necessary. When changing race data, also consider any scoreboard, PlaceholderAPI or nametag consumers. Race placeholders include `%levelcraft_race%`, `%levelcraft_race_display%`, `%levelcraft_race_id%`, `%levelcraft_race_drawback%` and `%levelcraft_race_drawback_description%` in the referenced expansion.

See [Paths](paths.md) for the second character identity choice.
